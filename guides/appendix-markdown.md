# 付録：Markdownの書き方

本講座の実習ではMarkdownファイルを編集します。この付録では、実習で使うMarkdownの記法をまとめています。

> **補足：** Code Serverではファイルを右クリックして「Open Preview」を選ぶと、Markdownの表示結果をリアルタイムで確認できます。

---

## 見出し

`#` の数で見出しのレベルが変わります。`#` の後には半角スペースを1つ入れてください。

```markdown
# 大見出し（h1）
## 中見出し（h2）
### 小見出し（h3）
```

### 表示結果

# 大見出し（h1）
## 中見出し（h2）
### 小見出し（h3）

> **講座での使い方：** `#` はページタイトル（例：`# バーガーメニュー`）、`##` はメニュー項目名（例：`## クラシックバーガー`）に使います。

---

## 段落

文章は普通に書くだけで段落になります。段落を分けるには**空行を1行**入れてください。

```markdown
粗挽きビーフ100%パティにフレッシュトマト、レタス、オリジナルソースを合わせた定番の一品。

たっぷりのアボカドスライスと濃厚チェダーチーズをトッピング。
```

> **注意：** 空行を入れずに改行だけすると、段落が分かれずにつながって表示されます。

---

## 太字

`**` で囲むと太字になります。

```markdown
**¥1,200**
```

### 表示結果

**¥1,200**

> **講座での使い方：** メニューの価格表示に使います。

---

## リスト

行頭に `- ` を付けると箇条書きになります。`- ` の後には半角スペースを1つ入れてください。

```markdown
- 平日: 11:00 - 21:00
- 土日祝: 10:00 - 22:00
- 定休日: 毎週水曜日
```

### 表示結果

- 平日: 11:00 - 21:00
- 土日祝: 10:00 - 22:00
- 定休日: 毎週水曜日

> **講座での使い方：** 営業時間やメニューリンクの一覧に使います。

---

## リンク

`[表示テキスト](リンク先)` の形式で、他のファイルやページへのリンクを作れます。

```markdown
[← トップに戻る](README.md)
[バーガーメニュー](burgers.md) — 自慢のグルメバーガーをご紹介
```

### 表示結果

[← トップに戻る](README.md)
[バーガーメニュー](burgers.md) — 自慢のグルメバーガーをご紹介

> **講座での使い方：** 各ファイルからREADME.mdへの「トップに戻る」リンクや、メニューページ間の相互リンクに使います。

---

## 水平線

`---` だけの行を書くと水平線（区切り線）になります。前後に空行を入れてください。

```markdown
## クラシックバーガー

粗挽きビーフ100%パティにフレッシュトマト。

**¥1,200**

---

## アボカドチーズバーガー
```

> **講座での使い方：** メニュー項目の間の区切りに使います。

---

## 引用

行頭に `> ` を付けると引用（囲み表示）になります。

```markdown
> バーガーメニューは [こちら](burgers.md) からどうぞ。
>
> サイドメニューは [こちら](sides.md) からどうぞ。
```

### 表示結果

> バーガーメニューは [こちら](burgers.md) からどうぞ。
>
> サイドメニューは [こちら](sides.md) からどうぞ。

> **講座での使い方：** 関連ページへの案内に使います。引用内で空行を入れる場合は `>` だけの行を挟みます。

---

## まとめ

| 記法 | 書き方 | 用途 |
|---|---|---|
| 見出し | `# テキスト` / `## テキスト` | ページタイトル、セクション名 |
| 段落 | 空行で区切る | 説明文 |
| 太字 | `**テキスト**` | 価格表示 |
| リスト | `- テキスト` | 箇条書き |
| リンク | `[表示テキスト](ファイル名)` | ファイル間リンク |
| 水平線 | `---` | 項目の区切り |
| 引用 | `> テキスト` | 案内・補足 |
