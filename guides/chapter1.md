# 第1章：Gitを使う準備

この章では、Gitを使い始めるための土台を作ります。Gitがインストールされていることを確認し、コミットに記録されるユーザー情報を設定します。

---

## 1-1. バージョン管理の必要性

ファイルを編集していて、こんな経験はありませんか？

- `報告書_最終版.docx`
- `報告書_最終版2.docx`
- `報告書_最終版_修正済み.docx`

ファイル名に「最終版」や日付を付けて管理する方法は、すぐに破綻します。どれが本当の最新版かわからなくなり、いつ・誰が・何を変更したのかも追えません。

**Git**は、ファイルの変更履歴を安全に記録・管理するための「バージョン管理システム」です。Gitを使えば、以下のことができるようになります。

- 過去の任意の時点に戻せる
- いつ・誰が・何を変更したかがわかる
- 複数人で同じファイルを安全に編集できる

---

## 1-2. Gitのインストール確認

この実習環境（Code Server）にはGitがインストール済みです。ターミナルを開いて、バージョンを確認しましょう。

### 手順

ターミナルで以下のコマンドを実行します。

```bash
git --version
```

### 期待される出力

```
git version 2.xx.x
```

バージョン番号が表示されれば、Gitは正しくインストールされています。

> **補足：** バージョン番号は環境によって異なりますが、本講座の内容はGit 2.x系であれば問題なく動作します。

---

## 1-3. Gitの初期設定

Gitでコミット（変更の記録）を行うと、「誰がその変更をしたか」がユーザー名とメールアドレスで記録されます。まだ設定していない場合はここで設定しましょう。

### 手順1：ユーザー名の設定

以下のコマンドを実行します。`自分の名前` の部分は自分の名前に置き換えてください。

```bash
git config --global user.name "自分の名前"
```

> **補足：** `--global` オプションを付けると、このPC上のすべてのリポジトリに対して設定が適用されます。

### 手順2：メールアドレスの設定

以下のコマンドを実行します。`自分のメールアドレス` の部分は自分のメールアドレスに置き換えてください。

```bash
git config --global user.email "自分のメールアドレス"
```

### 手順3：設定内容の確認

設定が正しく反映されたか確認します。

```bash
git config --list
```

### 期待される出力

出力の中に、先ほど設定した `user.name` と `user.email` が含まれていれば成功です。

```
user.name=自分の名前
user.email=自分のメールアドレス
```

> **補足：** `git config --list` の出力には他の設定項目も表示されますが、ここでは `user.name` と `user.email` の2行が確認できれば問題ありません。

## この章のまとめ

この章で学んだコマンドは以下の3つです。

| コマンド | 用途 |
|---|---|
| `git --version` | Gitのバージョン確認 |
| `git config --global user.name "名前"` | ユーザー名の設定 |
| `git config --global user.email "メール"` | メールアドレスの設定 |
| `git config --list` | 設定値の一覧表示 |
